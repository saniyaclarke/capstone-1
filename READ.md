# PennyTrack - Accounting Ledger Application

## Project Details

PennyTrack is a Java application that allows users to not only  track, but ammend and add financial transactions.

The purpose of this project is to
Create a smoother way to pull financial information whether that be for personal or Business use.

## Features

- Add deposits
- Record payments
- View all transactions
-Save and load transactions using a CSV file
- Sort transactions from newest to oldest
- Generate Month-to-Date reports
- Generate Previous Month reports
- Generate Year-to-Date reports
- Generate Previous Year reports
- Search transactions by vendor


## Technologies Used

- Java
- IntelliJ IDEA
- ArrayList
- CSV File Handling
- LocalDate and LocalDateTime
- Ninjava

## How to Run the Application

1. Open PennyTrack in IntelliJ IDEA.
2. Locate PennyTrackApplication.java.
3. Make sure transactions.csv is in src/main/resources.
4. Run the main() method.
5. Follow the menu options in the console.
